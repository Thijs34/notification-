# Push Test (PWA)

A minimal PWA that shows web push notifications working on **Android** and **iOS**,
plus a **Send** tab where you type a message on your PC and push it to your phones.

- **Receive tab** (phones): enable notifications and send yourself a test push.
- **Send tab** (PC): pick registered devices, type a title and message, then press Send.

Stack: Vite + React frontend, Vercel serverless functions in `/api` (using `web-push`),
and Upstash Redis to store the device list.

## Deploy to Vercel

1. **Push this folder to GitHub** and import it at <https://vercel.com/new>.
   Vercel auto-detects Vite, so no build settings are needed. (Or run `npx vercel`.)

2. **Add environment variables** under Project → Settings → Environment Variables:

   | Name                | Value                                                    |
   | ------------------- | -------------------------------------------------------- |
   | `VAPID_PUBLIC_KEY`  | from `.env.local`                                        |
   | `VAPID_PRIVATE_KEY` | from `.env.local` (keep this secret)                     |
   | `VAPID_SUBJECT`     | `mailto:` + your email address                           |
   | `ADMIN_PASSWORD`    | any password; the Send tab asks for it (recommended)     |

   `.env.local` already contains a generated key pair. To make a new one, run
   `npm run vapid -- --force`.

3. **Connect a database** for the device list: Project → Storage → Create Database →
   **Upstash for Redis** (the free plan is enough) → connect it to this project. Vercel adds
   `KV_REST_API_URL` and `KV_REST_API_TOKEN` automatically.

4. **Redeploy** (Deployments → ⋯ → Redeploy). New environment variables only apply
   to new deployments.

Use the **production URL** (`your-project.vercel.app`) on your phones. Preview URLs
sit behind Vercel's login wall.

## Testing

**Android (Chrome)**
1. Open the site and tap **Enable notifications**, then **Allow**.
2. Tap **Send test now**, or **Send in 5s** and lock the phone.

**iPhone / iPad (iOS 16.4+)**: on iOS, push only works from the home screen.
1. Open the site in Safari, tap **Share** (on iOS 26, tap **•••** first), then
   **Add to Home Screen**.
2. Open **Push Test** from the home screen.
3. Tap **Enable notifications**, then **Allow**.
4. Tap **Send test now**, or **Send in 5s** and lock the phone.

**From your PC**: open the same URL and go to the **Send** tab. Enter the admin password,
type a message, and press **Send** (or Ctrl + Enter). Every phone that enabled
notifications appears in the list.

## Troubleshooting

- **Nothing arrives on iPhone:** check Settings → Notifications → Push Test, and make
  sure Focus / Do Not Disturb is off.
- **Nothing arrives on Android:** make sure Chrome's notifications are allowed in
  Android Settings → Apps → Chrome → Notifications.
- **You changed the VAPID keys:** every old subscription stops working. On each
  phone, tap **Turn off notifications** and then **Enable** again.
- **The phone shows "Listed on Send tab: No (no database)":** Redis isn't connected
  yet (step 3 above), or you haven't redeployed since connecting it.

## Local development

`npm run dev` serves the UI only, because the `/api` functions need Vercel's runtime.
To run everything locally, use:

```sh
npx vercel dev
```

This reads `.env.local`. Push notifications need HTTPS, so test on real phones with
the deployed site.

## Files

```
api/
  vapid-public-key.js   GET  public key for subscribing
  subscribe.js          POST save a device's subscription (Redis)
  unsubscribe.js        POST remove a device
  send.js               POST push to one subscription ("send to myself", optional delay)
  devices.js            GET  list devices          (admin password)
  broadcast.js          POST push to chosen devices (admin password)
  _lib/shared.js        helpers (not an endpoint)
public/
  sw.js                 service worker: shows the notification, handles clicks
  manifest.webmanifest  PWA manifest (display: standalone is required on iOS)
  icons/                generated by `npm run icons`
src/
  Receiver.jsx          phone UI: install steps, permission, test buttons
  Sender.jsx            PC UI: device list and message textbox
```
